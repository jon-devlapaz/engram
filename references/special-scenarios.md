# Special scenarios

Procedures, not slogans. Use the matching one as soon as it applies
(usually at 0 / 0.5), not as a post-hoc apology in the honest boundary.

## Living vs historical

**Living subject**
1. Put a **research cutoff date** in the honest boundary and in ledger 06.
2. Ledger 06 must cover the last 12 months; if it cannot, mark that slice thin.
3. Prefer dated first-party output over undated biography.
4. After ship, updates are agents 2 + 5 + 6 (see Updates). Suggest a refresh
   when they next use a living engram older than the cutoff window they care
   about. Prefer a dated cutoff over inventing "what they think now."

**Historical subject**
1. Materials are more stable; the failure mode is **biography bias**
   (hagiography, one school's story, later myth).
2. Every model needs ≥2 independent source families (own writing vs
   later biographer vs contemporary critic). One famous biography is
   not enough.
3. Keep periodized thinking: early vs late. Prefer a dated life over one
   eternal personality.
4. Still set a cutoff (last source ingested). Later scholarship is uncovered.

## Topic skill vs person engram

Input is a field ("value investing", "product restraint"), not a name.
Write to `<skills-root>/engrams/<topic>-framework/`. Same tree. Variants:

| Phase | Person engram | Topic-skill variant |
|---|---|---|
| 0A | Confirm identity + focus | Confirm **topic boundary + audience** (Graham-style value, or the whole field?) |
| 0.5 | `[person]-engram/` | `[topic]-framework/`; same directory shape |
| 1 | Six agents around one person | First find 3–5 core people / schools, then assign agents (1–2 agents per person, not six on one) |
| 2.1 | One mind's models | **Field consensus** (what every school grants) + **splits** (A says X, B says Y) |
| 2.3 | One voice | Neutral, professional exposition (no role-play) |
| 2.4 | One person's tensions | Philosophical splits between schools (value vs growth, etc.) |
| 3 | `skill-template.md` as written | Drop role-play rules and identity card. Replace with "framework overview" + "school contrast" |
| 4 | Compare to their known stances | Compare to canonical cases in the field |

Offer a topic candidate when the ask is a field, not a celebrity.

## China vs West source playbook

Pick this at **Phase 0.5**, then bind Phase 1 agents to it.

### Blacklist (never use as sources)

- **Zhihu** — rewritten, high distortion; no ledger, no dimension
- **WeChat public accounts** — closed, unverifiable, mostly second-hand
- **Baidu Baike / Zhidao** — stale and unreliable
- Quote-aggregation / "best quotes" farms

### Chinese outlet allowlist (only these classes of Chinese media)

Named newsrooms, not blogs on WeChat: **36氪**, **极客公园**, **晚点 LatePost**,
**财新**, **第一财经**, **虎嗅**, **少数派**, **机器之心**, and equivalent
named outlets in that class. Interviews: original **Bilibili** video
(the person's own or the host's original upload — not a reupload
account), **小宇宙** / **喜马拉雅** original audio. Their own books and
Weibo are first-party. If it is not on this list and not first-party,
leave it out of Chinese sources.

**Chinese-language subject**
- First-party: their books, speeches, Weibo, original long interviews.
- Video / audio: original Bilibili uploads (not reupload accounts);
  Xiaoyuzhou / Ximalaya original audio.
- Press: only the Chinese outlet allowlist above.
- Blacklist above still applies.

**Western / English-language subject**
- First-party site, newsletters, papers, books (user-supplied or legal).
- YouTube originals + the caption scripts; podcasts via published
  transcripts (podcastnotes.org, the show's site) then captions.
- X / interviews / filings as dated primary.
- Amazon/Goodreads reviews are weak secondary (reader reaction), never
  a substitute for the book.

Mixed bilingual subjects: run **both** playbooks; label each item's
language and origin. Blacklist still applies to Chinese slices.

## Obscure person (<10 usable sources)

When 0.5 (or the first hunt) shows fewer than 10 unique usable sources:

1. **Warn at 0.5.** Tell them public material is thin and the skill
   will be capped. Surface this before Phase 4.
2. Drop the model count to **2–3**. Mark each "inferred from limited
   evidence."
3. **Expand the honest boundary**: name which dimensions are empty
   (usually decisions, external views, or last-12-months).
4. If they can supply primary files (books, internal recordings,
   messages they have a right to share), switch to local-first / pure-local
   and prefer those. Prefer user-supplied corpus over scraping private
   accounts.

## Distill yourself

When they say "distill me" / "make a skill of myself":

1. Engram cannot search the public web for *their* mind. They have to
   supply the corpus. Halt until files arrive.
2. Ask for: personal essays / blog; recorded talks or podcasts; decision
   memos; a self-description. Optional and user-supplied only: letters,
   messages, a trusted other person's written view (consent required).
3. Phase 1: six agents **read `sources/`**. Mix in a public corpus only
   when they have one and explicitly asked (then label `user-supplied`
   vs `web`).
4. **Self-serving-memory warning:** people over-weight flattering traits
   and skip blinds. Record that risk in the honest boundary. If they
   offer someone else's evaluation, file it as witness, not as "I am."
5. Intimate ledger 07 only from files they gave. False-memory veto still
   applies — Unrecorded when childhood/grief has no admitted trace.
