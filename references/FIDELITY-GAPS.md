## Lean ≠ delete Step-3 / Evidence classes

Writing-for-agents lean (short description, extracted special scenarios,
mind-first once in Defaults, concrete Step-2 look-ats) is a win.

What hurt runtime fidelity (~5 pts on the /100 scorecard; ~7 on the /300
fresh probe):

| Deleted / thinned in early v2 | Runtime tax |
|---|---|
| Explicit **Evidence classes** role rule | Weaker Subject/Witness/Inference labeling habit |
| Full **Step 3** sequence (stakes → mechanism → caveat → recommendation → dated tension → what would change my mind) | Answers read checklist-from-tracks more than live improvisation; consequential answers lighter |
| Dense **inline primary URLs** in Model Evidence (name-only cites) | Source transparency −2 |
| Self-contained Sources (URLs) vs research/ indirection only | Same −2 |
