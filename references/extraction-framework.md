# Extraction framework

> From raw corpus to runnable mental models.
> `references/extraction-framework.md`. Read this in Phase 2 before synthesis.
> Do not skip it. Do not improvise a lighter method.

## 1. Triple verification for mental models

A claim is a **mental model** only if it passes all three tests. Otherwise it
is a one-off remark or, at best, a heuristic.

### Test 1: Cross-domain recurrence

The same frame appears in at least two different domains the person discusses.

Example: Naval on leverage — wealth (code, media, capital, labor), personal
growth (specific knowledge + leverage = compounding), career choice (pick
work with leverage). Three domains → a real model.

### Test 2: Generative power

The model lets you infer a stance on a **new** question.

Example: if Munger's inversion is a model, "how to succeed" becomes "how to
guarantee failure"; "how to invest" becomes "how to go broke." It generates.

### Test 3: Exclusivity

Not every smart person thinks this way. The model is a distinguishing lens.

Example: antifragility is Taleb's. Universal wisdom fails this test.

| Result | What it becomes |
|---|---|
| 3/3 | Mental model |
| 1–2/3 | Decision heuristic |
| 0/3 | Drop it |

## 2. Quantifying expression DNA

### 2.1 Sentence fingerprint

Sample 20 random paragraphs from long-form writing or talks. Count:

| Dimension | Measure |
|---|---|
| Mean sentence length | words / sentences |
| Question ratio | questions / sentences |
| Analogy density | analogies per 1,000 words |
| First-person rate | I / me / my frequency |
| Certainty mix | must/obviously vs maybe/perhaps |
| Turn frequency | but/however/still per 1,000 words |

### 2.2 Style poles

Tag each pole. Do not land in the middle out of timidity.

```
formal ←→ colloquial
abstract ←→ concrete
hedged ←→ asserted
academic ←→ plain
long-sentence ←→ short-sentence
setup-first ←→ conclusion-first
data-driven ←→ narrative-driven
```

### 2.3 Taboo words and tics

- Words they never use → the runtime never uses.
- Tics and high-frequency phrases → use sparingly. Too many is cosplay.

## 3. Contradiction handling

Contradiction is personality, not a bug to fix.

1. **Temporal** — early A, later B. Record the arc. Runtime prefers the later
   view and names the change.
2. **Domain** — X at work, Y in life. Keep both. Do not unify.
3. **Essential tension** — values that pull against each other. File under
   unresolved tensions. This is usually the interesting part.

Wrong: pick a side, invent a reconciliation, pretend the clash is not there.

## 4. When information is thin

| Situation | Handling |
|---|---|
| A dimension has little public record | Label "thin evidence; this slice is inferred" |
| Only secondary sources | Lower confidence; "according to [source]" |
| Irreconcilable conflict | Present both. Do not pick. |
| They refuse the topic | Honor the silence. Do not write a clever compromise. |

## 5. Person skill vs topic skill

| | Person | Topic |
|---|---|---|
| Core | One mind | A field's toolkit |
| Models | Mostly one person | Several schools |
| Voice | Theirs | Neutral-professional |
| Contradiction | Inner tension | Inter-school split |
| Validation | Their known stances | Field consensus |

## 6. Quality self-check (Phase 3–4)

### Mental models
- [ ] Each model has evidence in at least two domains
- [ ] Count is 3–7 (fewer is shallow; more is unextracted)
- [ ] Each has an application and a failure condition
- [ ] Models have tension without being mush

### Expression DNA
- [ ] Recognizable, not generic assistant
- [ ] Not a caricature
- [ ] Core features, not surface mimicry

### Decision heuristics
- [ ] Each rule has a concrete case
- [ ] Each can fire on a *new* situation

### Honest boundary
- [ ] Names what it cannot do
- [ ] Names sources and research date
- [ ] Names thin dimensions

### Whole
- [ ] Running the framework on a new problem yields a distinctive view
- [ ] Not a collage of quotes
- [ ] With the name removed, the thinking is still recognizable

## 7. Additive: memory-trace admission (engram only)

Beyond mind + voice, Engram also admits **memories**. A candidate
trace enters `MEMORY.md` only if it passes the four documentary tests
(specificity, reactivation, sufficiency, necessity) in `CONSTITUTION.md`.
This section does not replace §1–6. Thin or invented episodes fail here
the way ungrounded "models" fail triple verification.
